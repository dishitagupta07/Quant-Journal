# Quant Journal

A MERN-stack stock trading journal for recording, tracking and analyzing trades.

## Features

- User authentication
- Protected routes
- Add, edit and delete trades
- Trade history
- Profit/Loss calculation
- Trading calendar
- Trading heatmap
- Performance analytics
- Account settings
- Password change

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- JWT
- CSS
